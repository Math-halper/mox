# Algebra

Algebra uses letters (variables) to stand for numbers and describes relationships with equations, expressions, and functions. It is the language of patterns.

## Expressions versus equations

An expression has no equals sign, e.g. 3x + 5. An equation states that two expressions are equal, e.g. 3x + 5 = 20. You simplify expressions and solve equations.

## Vocabulary

- Term: a part separated by + or −. In 4x² − 3x + 7 there are three terms.
- Coefficient: the number multiplying a variable (4 and −3 above).
- Constant: a term with no variable (7).
- Like terms: identical variable parts, which can be combined: 5x + 2x = 7x, but 5x + 2x² cannot be combined.

## Linear equations in one variable

Solve by undoing operations in reverse order, keeping the equation balanced.

Example: 4x − 7 = 21 → add 7 → 4x = 28 → divide by 4 → x = 7.

If variables appear on both sides, collect them on one side: 5x + 3 = 2x + 18 → 3x = 15 → x = 5.

Special cases: an equation such as 2(x + 3) = 2x + 6 is true for every x (identity); 2x + 3 = 2x + 7 has no solution.

## Inequalities

Solve like equations, but reverse the inequality symbol when multiplying or dividing by a negative number. −3x > 12 gives x < −4. Graph solutions on a number line: open circle for < or >, closed circle for ≤ or ≥.

## Linear equations and graphs

A line is y = mx + b, where m is the slope and b the y-intercept. Slope = rise/run = (y₂ − y₁)/(x₂ − x₁). A horizontal line has slope 0; a vertical line has undefined slope. Parallel lines have equal slopes; perpendicular slopes are negative reciprocals (2 and −½). Point-slope form: y − y₁ = m(x − x₁). Standard form: Ax + By = C.

## Systems of equations

Two lines can cross once (one solution), never (parallel, no solution), or coincide (infinitely many). Solve by substitution, elimination, or graphing.

Example with elimination: 2x + y = 11 and x − y = 1. Add: 3x = 12, so x = 4 and y = 3.

## Exponent and polynomial rules

- Product: xᵃ · xᵇ = xᵃ⁺ᵇ
- Quotient: xᵃ / xᵇ = xᵃ⁻ᵇ
- Power of a power: (xᵃ)ᵇ = xᵃᵇ
- Negative exponent: x⁻ᵃ = 1/xᵃ
- Fractional exponent: x^(1/2) = √x

Multiply binomials with FOIL: (x + 3)(x − 5) = x² − 5x + 3x − 15 = x² − 2x − 15. Notable products: (a + b)² = a² + 2ab + b²; (a + b)(a − b) = a² − b².

## Factoring

Common patterns:
- Greatest common factor: 6x² + 9x = 3x(2x + 3)
- Difference of squares: x² − 25 = (x + 5)(x − 5)
- Simple trinomial: x² + 7x + 12 = (x + 3)(x + 4), since 3 × 4 = 12 and 3 + 4 = 7.

## Quadratic equations

Standard form ax² + bx + c = 0.

- Factoring: x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 or 3.
- Quadratic formula: x = (−b ± √(b² − 4ac)) / 2a.
- Completing the square rewrites the equation as a perfect square.

The discriminant b² − 4ac tells how many real solutions exist: positive → two, zero → one, negative → none (two complex).

## Functions

A function pairs each input with exactly one output. Notation f(x) = 2x + 1 means substitute the input: f(3) = 7. The domain is the set of allowed inputs; the range is the set of outputs. Test with the vertical line rule on a graph.

Common families:
- Linear: y = mx + b (constant rate of change)
- Quadratic: y = ax² + bx + c (parabola; vertex at x = −b/2a)
- Exponential: y = a·bˣ (repeated percent growth or decay)
- Absolute value: y = |x| (V shape)

## Logarithms

A logarithm answers "what exponent gives this number?": log₂ 8 = 3 because 2³ = 8. Rules: log(xy) = log x + log y; log(x/y) = log x − log y; log(xⁿ) = n log x. Natural log ln uses base e ≈ 2.71828.

## Sequences and series

Arithmetic sequences add a constant: 3, 7, 11, 15 (common difference 4), nth term aₙ = a₁ + (n − 1)d. Geometric sequences multiply by a constant: 2, 6, 18, 54 (common ratio 3), nth term aₙ = a₁ · rⁿ⁻¹. An arithmetic series sums to n(a₁ + aₙ)/2.
